# Claude / ChatGPT / Grok Prompt Libraries

This directory contains curated prompt templates and libraries for various AI platforms.

## Overview
A comprehensive collection of AI prompts optimized for Claude, ChatGPT, Grok, and other language models.

## AI Platforms Supported
- **Claude** (Anthropic)
- **ChatGPT** (OpenAI)
- **Grok** (xAI)
- Other LLM platforms

## Categories
- `business/` - Business operations and strategy prompts
- `technical/` - Development and technical prompts
- `creative/` - Content creation and design prompts
- `analysis/` - Data analysis and research prompts
- `automation/` - Workflow automation prompts
- `grant-writing/` - Grant proposal and writing prompts

## Usage
1. Browse the category folders
2. Select a relevant prompt template
3. Customize variables and context
4. Use with your preferred AI platform

## Contributing
When adding new prompts:
- Use clear, descriptive filenames
- Include usage instructions
- Document expected outputs
- Tag with relevant categories
